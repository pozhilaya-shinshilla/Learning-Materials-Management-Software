# Сервис управления учебными материалами — Backend (этап 1)

Реализация backend-логики согласно техническому заданию (раздел 4), на текущем этапе —
в виде самостоятельных Python-классов с CLI-интерфейсом, без поднятия HTTP-сервера и БД.
Архитектура подготовлена так, чтобы слой хранения можно было заменить на PostgreSQL +
SQLAlchemy, а CLI — на FastAPI-роуты, без изменения бизнес-логики (см. «Дальнейшие шаги»).

## Стек

- Python 3.12
- Менеджер пакетов и окружений: [uv](https://docs.astral.sh/uv/)
- Зафиксированные зависимости будущих этапов: FastAPI, SQLAlchemy, Alembic, Pydantic —
  см. `pyproject.toml` и `uv.lock` (текущий этап их ещё не использует в коде)
- Линтер/форматтер: [ruff](https://docs.astral.sh/ruff/)

## Структура репозитория

```
.
├── pyproject.toml        # метаданные проекта и зависимости (uv)
├── uv.lock               # зафиксированные версии зависимостей (генерируется uv, не редактируется руками)
├── README.md
├── docs/                 # документация проекта
│   └── architecture.md
└── src/                  # весь исходный код
    ├── main.py            # точка входа — минимум кода, только сборка и запуск
    ├── bootstrap.py       # композиция зависимостей (DI-корень), сидирование admin-аккаунта
    ├── config.py          # константы (допустимые форматы файлов, макс. размер)
    ├── domain/            # сущности, enum'ы, исключения — не зависят ни от чего
    ├── repositories/      # интерфейсы репозиториев (ABC) + in-memory реализация
    ├── security/          # хеширование паролей (интерфейс + PBKDF2)
    ├── services/          # бизнес-логика (auth, materials, search, favorites, users, log)
    └── cli/               # терминальный интерфейс поверх сервисов
```

## Запуск

### 1. Требования

- Python 3.12 или новее — https://www.python.org/downloads/ (на Windows не забудьте
  поставить галку «Add python.exe to PATH» в установщике);
- менеджер пакетов **uv** (рекомендуется, но не обязателен — см. вариант без uv ниже).

Установка uv:

```bash
# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```

После установки закройте и откройте терминал заново и проверьте: `uv --version`.

### 2. Получить код

```bash
git clone <ссылка на репозиторий>
cd sms
```

### 3. Установить зависимости и запустить

```bash
uv sync            # создаст .venv и установит fastapi/sqlalchemy/alembic/pydantic/ruff
                    # по версиям, зафиксированным в uv.lock
uv run -m src.main
```

Если uv недоступен (например, нет доступа к сети или ставить его не хочется), а Python 3.12+
уже есть — можно запустить без установки сторонних пакетов, так как текущий этап их не
использует в коде:

```bash
python3 -m src.main
```

### 4. Вход в систему

При первом запуске автоматически создаётся администратор:

```
логин:  admin
пароль: admin123
```

Залогинившись под ним, вы попадаете в меню — дальше все действия (создание пользователей,
дисциплин, материалов и т.д.) выполняются через пункты меню. Полный список пунктов по ролям —
в разделе «Роли и возможности CLI» ниже.

Смените этот пароль или удалите сид, прежде чем переходить к реальному развёртыванию.

## Загрузка и скачивание файлов

При создании материала (пункт «Добавить материал») указывается **локальный путь** к файлу на
диске — формат и размер определяются автоматически по расширению и содержимому файла, вводить
их вручную не нужно. Файл физически копируется в `data/uploads/` (папка создаётся сама, в
`.gitignore` уже добавлена). При скачивании материал копируется из хранилища в указанную папку
(по умолчанию — текущая).

## Валидация при регистрации пользователей

- логин: 3–32 символа, латиница/цифры/`_`/`-`
- email: должен соответствовать формату `local@domain.tld`, обязана быть уникальность (как и у логина)
- пароль: не короче 8 символов

## Ролевая модель

Права накапливаются: у преподавателя есть все действия студента + свои, у администратора — все
действия преподавателя (а значит и студента) + управление пользователями и журналом событий.
Администратор не может заблокировать или удалить собственную учетную запись.

## Роли и возможности CLI

| Роль          | Возможности в меню                                                                 |
|---------------|--------------------------------------------------------------------------------------|
| Студент       | каталог, поиск/фильтрация, скачивание, избранное                                    |
| Преподаватель | каталог, создание/редактирование/удаление материалов, поиск, дисциплины и темы      |
| Администратор | пользователи (создание/роль/блокировка/удаление), просмотр журнала событий          |

Регистрация новых пользователей выполняется только администратором — согласно п. 4.1.6.6 ТЗ.
